# The Lot

Free mixtape press. Unsigned and independent artists drop singles, tapes, and videos. Listeners stream on the wall or cop the file onto their phone and play it with no signal.

No store. No per-stream payout. Ads and paid promo slots keep the lights on. Post only what you own, or what a label approved in writing. Rights holders can pull a tape from the desk.

The tapes already on the wall are original pressings made for this place, so the preview can play without anyone else's masters. Drops you make stay on this device.

## Run it

```bash
npm install
npm run dev
```

Open the app at `http://localhost:8080`.

## What's in the press

- **Wall** — new tapes, most copped, promo banner
- **Drop** — post a single, mixtape, or video you own
- **Phone** — saved files play with the signal off
- **Promote** — sticker, front row, or banner
- **Rights desk** — takedown for material you do not own
